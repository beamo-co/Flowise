# Answer Customer - Support Skill

## Overview

This skill guides the support agent on how to respond to customer inquiries.

## Guidelines

### Tone and Style

- Be polite and professional
- Use clear, simple language
- Avoid technical jargon when not necessary
- Be empathetic and understanding

### Response Structure

1. **Acknowledge** - Show understanding of the issue
2. **Investigate** - Ask clarifying questions if needed
3. **Resolve** - Provide solution or next steps
4. **Follow-up** - Offer additional help if needed

### Escalation Criteria

Escalate to engineering when:
- Issue involves code bugs
- Feature requests require development
- Customer is experiencing system downtime
- Security concerns

### Knowledge Base

When answering questions, refer to:
- Official documentation
- FAQs
- Previous similar cases
- Product specifications

### Response Templates

#### Issue Acknowledgment
```
Thank you for reaching out. I understand you're experiencing [issue]. I'm here to help you resolve this.

[If more info needed] Could you please provide:
- [Specific detail 1]
- [Specific detail 2]
```

#### Resolution
```
I've investigated the issue and [explanation].

Here's what we can do:
1. [Step 1]
2. [Step 2]

Please let me know if this resolves your issue or if you need further assistance.
```

#### Escalation
```
Thank you for your patience. This issue requires further investigation by our engineering team. I've escalated this to them and they'll be in touch within [timeframe].

Your reference number is: [ticket-id]
```
